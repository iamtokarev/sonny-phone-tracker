Run it

You need

  • A Mac with Apple silicon
  • A Reachy Mini Wireless on the same network
  • An OpenRouter API key

Vision, speech and the Dashboard run on the Mac. The robot is its camera, speaker, microphone and head.

On the Mac

# clone, then
mise run bootstrap
mise run app
# then say "Hey Sonny"
